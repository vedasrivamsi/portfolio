> **Live Website:** [vedasrivamsi.github.io/portfolio](https://vedasrivamsi.github.io/portfolio/)

Welcome to my personal developer portfolio website featuring **VamAI** — a custom intelligent AI assistant built to answer recruiter questions about my background, skills, internships, certifications, and projects!

---

## ✨ Features

- 🤖 **VamAI Engine**: Natural language intent processing with context-aware precision sub-intents (B.Tech CGPA, Intermediate %, Class 10 %, specific skill inquiries).
- 📜 **In-Page Certificate Preview Modal**: Interactive PDF & image viewer for all 10+ certificates (AWS, NxtWave, GUVI, StudentTribe, CISCO, RINL, InternPe, Brainovision).
- 📄 **In-Page Resume PDF Preview Modal**: In-page PDF preview modal with direct download button and glassmorphism backdrop blur.
- 🏷️ **Interactive Project Category Filter Tabs**: Instant filtering across `All Projects`, `🤖 AI & ML`, `🌐 Full Stack`, and `☕ Core Java`.
- 📋 **One-Click Copy Email**: Instant email clipboard copying with floating toast notification feedback.
- 🎯 **Interactive Stat Navigation**: Clickable stats and hero badges with smooth scrolling to respective sections.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Vanilla CSS with Dark + Gold Theme), JavaScript (ES6+)
- **Libraries:** FontAwesome 6.5.1, VanillaTilt.js
- **Bot Engine:** `knowledgeBase.js` + `vamai-widget.js` (No external backend required!)
